# Biotian-mision-reino-vegetal
Recurso e-learning interactivo sobre clasificación y reproducción vegetal, desarrollado con HTML, CSS y JavaScript.

## Descripción

Este proyecto presenta un recurso e-learning con enfoque visual e interactivo. Incluye evaluación inicial y final, mapa de misiones, actividades de repaso, personajes desbloqueables y generación de informe automático de aprendizaje.

## Objetivo

Transformar contenido curricular de botánica en una experiencia digital estructurada, útil para contextos de formación, demostración de diseño instruccional y portfolio profesional.

## Funcionalidades

- Test inicial de conocimientos.
- Mapa de misiones con progresión.
- Actividades interactivas de preguntas y respuestas.
- Pantallas de emparejamiento e identificación.
- Personajes desbloqueables.
- Test final con resultado e informe descargable.
- Interfaz visual orientada a presentación profesional.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Estructura del proyecto

```text

README.md
```

## Cómo usarlo

1. Descargar o clonar el repositorio.
2. Abrir `index.html` en el navegador.

Si se publica con GitHub Pages, también puede visualizarse directamente desde el navegador sin instalación local.
